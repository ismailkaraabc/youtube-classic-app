youtube-classic analytics

A private, single-user tool. It reads the YouTube Analytics and YouTube Data API (read-only) for the owner's own channels (Lumen Sonata, Nagme Sandigi, Seeing Is Proving, Etre Finance, Half Second) so the owner can see views, watch time, audience retention and thumbnail click-through for each video. It is not offered to the public.
